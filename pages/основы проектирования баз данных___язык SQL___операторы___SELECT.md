- Синтаксис
	- SELECT [ALL|DISTINCT] список_возращаемых_столбцов | *
		- FROM список_имен_столбцов
			- [WHERE условие_поиска]
				- состоит из ключевого слова WHERE, за которым следует условие поиска, определяющее, какие именно строки требуется выбрать
				- если
					- условие поиска имеет значение TRUE
						- строка будет включена в результат запроса
					- условие поиска имеет значение FALSE или NULL
						- строка исключается из результата запроса
				- условия отбора строк
					- сравнение
						- выражение1 = | <> | <|> | <=|> | >= выражение2
					- проверка на принадлежность диапазону значений
						- выражение [NOT] BETWEEN минимум AND максимум
					- проверка на принадлежность множеству
						- выражение [NOT] IN (набор_констант)
					- проверка на соответствие шаблону
					- имя_столбца [NOT] LIKE шаблон [ESCAPE символ_пропуска], где
						- шаблон - строка, в которую может входить один или более подстановочных знаков:
							- % - совпадает с любой последовательностью из нуля или более символов
							- _ - совпадает с любым отдельным символом
							- символ пропуска используется для проверки наличия в строках символов, использующихся в качестве подстановочных знаков (%, _)
			- [GROUP BY список_имен_столбцов]
			- [HAVING условие_поиска]
			- [ORDER BY имя_слобца [ASC|DESC]]
- Цель
	- получение списка возвращаемых столбцов, разделённых символом "запятая"
		- вывод значения определённых столбцов из таблиц, указанной в предложении FROM
- для вывода всех столбцов из таблицы можно перечислить их все названия или воспользоваться символом "*"
- DISTINCT исключает повторяющиеся значения столбца
- В предложении SELECT кроме имени столбцов и выражений с ними можно указывать константы, и константные выражения
- преложение FROM содержит список имен таблиц, разделённых символом ","
	- можно указывать синонимы (псевдонимы) имен таблиц
		- Например: FROM Students *st*, Groups *gr*
